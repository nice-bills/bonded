Bonded

Agents buy a guarantee before they act. An open-weight underwriter prices each action. If it won't insure it, the agent doesn't do it.

1 · An agent asks for cover

Payrun, the payments agent for Tetteh & Co., must buy a guarantee before it pays each invoice. Pick a case and request cover.

The underwriter reads every document above in one call, images included, and prices the action.

2 · Something went wrong: claims

A claims judge on the same pinned weights reads the original case, the quote and the evidence together. SERV Reasoning audits it. Approved claims are paid from the pool on chain.

Pick a claim.

Why open weights

Loss history only means something if the underwriter stays the same.

Closed models get swapped or pulled. Bonded pins DeepSeek-V4.1-Flash (MIT weights) served by Dolphin, records the serving fingerprint, and hashes the rating guide.

Every decision can be re-checked.

The exact request is stored by hash. Anyone, including a claimant, can re-run it on the same open weights and compare. Press “Re-check” on any quote or claim.

The model estimates; code does the money.

Dolphin returns per-peril probabilities with cited evidence. Bonded's code prices: cover × p(loss) × 1.4, declines above 10%, and never bonds more than 25% of free pool capital.

Two lines of defence from SERV.

SERV Prompt Guard screens every untrusted document; a SERV Shadow Agent audits each quote and claim against the rating rules. Either can veto.
