# Bonded brand

**Mark:** a seal (thin outer ring, solid disc) with a slanted geometric B, from the console's ring favicon and italic wordmark.
**Colors:** green `#2f5d3a`, ink `#111111`, paper `#fffff8`; dark mode: green `#8cc59b` on `#151411`, ink `#ece6d6`.
**Wordmark:** Inter ExtraBold Italic, tight tracking.

| File | Use |
|---|---|
| bonded-mark.svg / -1024.png | primary mark (light backgrounds) |
| bonded-mark-dark.svg / -1024.png | dark backgrounds |
| bonded-mark-mono.svg / -1024.png | one-colour (ink) |
| bonded-lockup.png, bonded-lockup-dark.png | mark + wordmark (SVG versions use live Inter text; prefer the PNGs) |
| x-avatar-400.png | X profile picture |
| x-header-1500x500.png | X header |
| favicon.svg, favicon-64.png | favicon (no outer ring, reads at 16 px) |

Sources: `src/make.py` writes the SVGs; `src/banner.html` is the header.
